# Resources and References

## 1. Official ZayRide Resources

### ZayRide Official Website
https://www.zayride.com/

**Purpose:** Used to understand ZayRide's transportation services, passenger journey, ride requests, driver matching, and delivery services.

### ZayRide Passenger — Archived Application Listing
https://chrome-stats.com/d/com.zayride.passenger

**Purpose:** Used to research historical information about the ZayRide Passenger application and its archived listing.

### AppBrain — ZayRide Passenger
https://www.appbrain.com/app/zayride-passenger/com.zayride.passenger

**Purpose:** Used as an additional historical reference for the former Passenger application.

**Evaluation note:** The original Passenger application was not installed or tested directly. Archived information and screenshots do not establish that the application is currently operational.

## 2. Android Development Resources

### Android Developers — Layouts in Views
https://developer.android.com/develop/ui/views/layout/declaring-layout

**Purpose:** Reference for creating Android user interfaces using XML layouts and Android Views.

### Android Developers — Layout Resources
https://developer.android.com/guide/topics/resources/layout-resource

**Purpose:** Reference for organizing and using XML layout files inside the Android `res/layout` directory.

### Android Developers — Accessibility for Views
https://developer.android.com/guide/topics/ui/accessibility/views/apps-views

**Purpose:** Reference for improving Android interface accessibility, readable controls, and accessible interaction.

## 3. UI/UX Design and Accessibility Resources

### Android Accessibility — Touch Target Size
https://support.google.com/accessibility/android/answer/7101858

**Purpose:** Reference for understanding recommended touch-target sizes and making interactive controls easier to use.

### Material Design — Accessibility
https://m1.material.io/usability/accessibility.html

**Purpose:** Reference for accessible interface design, visual clarity, color contrast, and usability principles.

### MDN — Understanding Color Contrast
https://developer.mozilla.org/en-US/docs/Web/Accessibility/Guides/Understanding_WCAG/Perceivable/Color_contrast

**Purpose:** Reference for understanding text contrast and improving readability.

## 8. Project Limitations

- The original ZayRide Passenger application was not installed or tested directly.
- The evaluation relies on publicly available information and archived screenshots.
- The current operational status of the original Passenger application could not be independently verified.
- A previous DBU student's ZayRide design has not yet been verified for comparison.
- The Android application is a static UI prototype.
- It does not implement real-time GPS, maps, driver matching, live ride booking, payment processing, driver tracking, or backend database services.
